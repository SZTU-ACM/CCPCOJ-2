CCPCOJ 用来举办 ICPC / CCPC 标准赛：建比赛、放题目、生成队伍和工作人员账号、抽机位、现场打印和气球、大屏榜单、直播叠加，以及闭幕式滚榜。

本仓库是使用说明和部署程序。站点以安装包的形式提供，这里没有源码。部署程序只提供 **Linux x86_64**。

## 开始

1. 打开 [Releases](https://github.com/SZTU-ACM/CCPCOJ-2/releases/latest)，下载 `csgoj-deploy_<版本>_linux_amd64`。
2. 按 [部署](doc/deploy_doc.md) 装好 Web，在「评测机管理」里复制命令，再装评测机。
3. 按 [办赛](doc/user_doc.md) 建一场标准赛。比赛大类选标准赛，子类型选 ICPC 或 CCPC。

## 一场比赛里要做的事

| | |
| --- | --- |
| 赛前 | 题目、队伍账号、密码条、机位、打印员和气球员 |
| 赛中 | 打印、气球、榜单、直播画面 |
| 赛后 | 获奖名单、滚榜、需要时的离线包 |

正式赛前把上面三项各走一遍。步骤和检查清单在 [办赛](doc/user_doc.md)。
